# 反詐指南 — 拆穿台灣常見的投資詐騙

> 這個工具叫「反詐投資王」，不是叫假的。
> 它存在的真正原因，就是台灣到處都是**假飆股群、假二群、假 VIP 群、假名師、
> 假績效截圖、保證獲利話術、詐騙幣與假投資平台**。
> 這份文件教你辨識它們，並用**統計與數學**戳破它們的承諾。

詐騙的共同核心只有一個：**用「倖存者偏差」與「精選證據」，讓你誤以為有穩賺的捷徑。**
而它們最怕的，就是你冷靜地把它的承諾丟進數學裡檢驗。

## 🛠 四個拆穿詐騙的工具

```bash
# 1. 貼上群組對話 / 廣告文案，掃描話術特徵（逐句標註）
anti-gambling-trader scan-text "老師帶單保證獲利，名額有限快加VIP"

# LINE 匯出的完整對話可直接掃描
anti-gambling-trader scan-text --file LINE對話.txt

# 2. 檢驗老師的宣稱：純靠運氣出現的機率有多高？
anti-gambling-trader guru-check --win-rate 0.9 --trades 10 --monthly-return 0.2

# 3. 用數學算出「連贏10次的神人」有多容易靠運氣出現
anti-gambling-trader survivorship --traders 1000 --streak 10

# 4. 鑑識老師/平台的報酬序列（過度平滑？高得可疑的夏普？）
anti-gambling-trader forensics --file 老師的月報酬.txt

# 互動式自我檢測
anti-gambling-trader scam-check
```

> 不同工具回答不同問題：`scan-text` / `scam-check` 只給可解釋的序數風險；
> `guru-check` / `survivorship` 才會在明示的虛無假設與參數下計算機率。
> 那些機率不是「某人是詐騙的機率」，也不能取代報案或司法鑑定。

`scan-text` 會辨識 LINE 的日期、時間與發言者，並只組合同一人在同一天、短時間內
拆開傳送的句子，避免把不同人的話拼成一段。報告會保留命中的原句與判斷理由；
它也會壓低「這是詐騙警語」「費用直接從款項扣除」等教育或否定語境的誤報。
風險只用極高／高／中／低表示，**低不等於安全**，也不是司法鑑定。

### LINE 掃描怎麼組合證據

| 規則 | 保守限制 |
|---|---|
| 拆句話術 | 只組合同一發言者、同一天、10 分鐘內的訊息 |
| 插話 | 中間可有別人插話，但回來時仍只能接原發言者 |
| 上限 | 最多 6 則、600 字，避免把整天內容硬湊成證據 |
| 不同人／不同日 | 永不拼接 |
| 否定與反詐引用 | 只作用在實際命中的子句；不會洗掉後續真正的匯款指令 |
| 遮字與簡繁體 | 正規化常見插空格、符號與簡繁變體，但仍可能漏掉新話術 |

掃描重點包括保證獲利、VIP／帶單導流、假績效、急迫與稀缺、異常入金、出金受阻、
先繳費才能出金，以及私人或指定收款處。這是人工規則與權重，不是經標註資料校準的
分類模型；它不能驗證身分、平台合法性或帳戶所有權。完整輸出判讀見
[完整功能與判讀指南](user-guide.md#6-line-對話詐騙辨識邏輯)。

## 被拉進飆股群 / LINE 投資群，是詐騙嗎？

**直接答案：** 風險很高。陌生人主動把你拉進 LINE 或 Telegram 群、
「老師」免費報明牌、學員集體曬獲利截圖，接著催你付費升級 VIP 或進二群 ——
這是台灣常見投資詐騙的典型流程。先不要匯款或付費，完整記錄老師的推薦
並用統計工具驗證，有疑慮就撥 165 查證。

> 本節對應的詐騙型態：**假飆股群 / 假 VIP 群 / 假二群**。

### 長什麼樣
- 有人**主動**把你拉進 LINE / Telegram 群，群裡「老師」每天報明牌。
- 群裡一堆「學員」貼獲利截圖、感謝老師，氣氛一片祥和。
- 先給你幾支「會漲」的股票嘗甜頭，再叫你**升級 VIP / 進二群**付費。
- 要你下載指定 App、加指定客服、或匯款到「老師合作的平台」。
- 禁止你公開質疑，提問會被踢或私訊安撫。

### 為什麼高度可疑
那些「學員」與截圖可能是樁腳、假帳號，也可能只呈現少數贏家；群內氛圍本身
無法驗證身分或完整績效。若同一招攬者對不同人提供不同方向，再只展示猜中的一組，
就能製造出「神準」印象 —— 這是倖存者偏差可被人為利用的方式。

### 怎麼拆穿
> 主動拉群、免費明牌與群友見證，都不能證明對方具可重複的交易能力。

把「老師」的歷史推薦**全部**記下來（含失敗的），用本工具算期望值 ——
如果結果為負或無法排除運氣，就沒有理由因少數精選成功案例繼續加碼。

## 「保證獲利」「穩賺不賠」的投資可信嗎？

**直接答案：** 不應據此匯款或下單。宣稱「保證獲利」「穩賺不賠」「零風險高報酬」
與真實市場風險不相容，也高度符合龐氏結構或假投資招攬的常見話術；先停止付款並查證。
「高勝率」也不等於賺錢：賺小賠大時，期望值仍可能是負的。
判斷投資時請看期望值，不要只看勝率。

> 本節對應的詐騙型態：**保證獲利 / 高勝率話術**。

### 長什麼樣
- 宣稱「保證獲利」「穩賺不賠」「零風險高報酬」。
- 強調「勝率 90% 以上」，卻從不提**賠的時候賠多少**。
- 用「月配 X%」包裝成像定存一樣安全。
- 催你「現在不進場就錯過」，製造急迫感。

### 為什麼高度可疑
這種宣稱隱藏或否認真實風險；即使沒有足夠資料判定是否構成犯罪，也不足以支持交付資金。
而「高勝率」本身會騙人：**勝率 90% 但賺小賠大，一次大賠就回吐所有獲利，期望值仍是負的。**

### 怎麼拆穿
> 如果穩賺，他為什麼要找你的錢，而不是去跟銀行無限借錢自己賺？

本工具的統計檢定，就是要拆穿「高勝率 = 賺錢」的幻覺 —— **看的是期望值，不是勝率。**

## 投資老師的對帳單 / 獲利截圖可以相信嗎？

**直接答案：** 先不要相信。獲利截圖可以修圖，也可以只挑賺錢的那幾天；
豪車名錶與學員見證，都無法證明真實的交易能力。
請要求完整、連續、夠長（數百筆以上）的交易紀錄，
再用統計檢定與樣本外驗證降低把運氣誤認成優勢的風險；它們仍可能有假陽性、
假陰性，也不能保證未來有效。

```bash
# 先整理截圖上可見的候選欄位；結果仍必須人工逐欄覆核
anti-gambling-trader scan-screenshot 績效截圖.png
```

這個指令可協助核對標的、點位、數量、損益正負號、幣別與已實現／未實現標籤，
但不能判斷圖片是否被裁切、修改或只挑贏單，更不能把單張圖變成完整績效證明。

> 本節對應的詐騙型態：**假名師 / 假績效截圖**。

### 長什麼樣
- 炫耀豪車、名錶、出國，暗示「跟我就能財富自由」。
- 貼「對帳單 / 獲利截圖」，但截圖可以 P、可以只挑賺的那幾天。
- 大量「學員見證」，卻沒有可驗證的長期、完整、第三方紀錄。
- 課程 / 訂閱費很貴，且強調「名額有限」。

### 為什麼高度可疑
截圖是**倖存者偏差**的完美載體：他只給你看賺的那幾筆，不給你看賠光退場的。
就算對帳單是真的，幾天的暴賺也無法證明任何優勢 —— 那可能只是運氣。
部分招攬者的主要收入可能來自學費與抽佣，而不是可驗證的交易績效。

### 怎麼拆穿
> 要求看「完整、連續、夠長（數百筆以上）」的交易紀錄，而不是精選截圖。

把那份紀錄丟進本工具做**顯著性檢定**與**樣本外驗證**，可降低被精選結果誤導的
機率，但不能完美區分能力與運氣，更不是未來獲利保證。

## 要求把錢匯到指定平台 / App 的投資，是詐騙嗎？

**直接答案：** 高度可疑。只要對方要求你把錢匯進「他指定的平台、錢包或 App」，
而不是你自己開戶、自己掌控的帳戶，就符合假投資平台常見手法。若平台由對方控制，
帳面獲利無法獨立驗證，小額出金也可能只是誘餌。
立刻停止匯款，保留證據並撥 165 查證。

> 本節對應的詐騙型態：**詐騙幣 / 假投資平台**。

### 長什麼樣
- 叫你把錢匯到某個「平台 / 錢包 / 交易所」，而不是你自己掌控的帳戶。
- 一開始能小額出金（誘餌），加碼後就「系統維護 / 要繳稅 / 要刷流水才能出金」。
- 網站 / App 很像知名交易所，但網址、下載來源不對。
- 宣稱「搬磚套利 / DeFi 高收益」穩賺，要你儲值參與。

### 為什麼高度可疑
若錢進入對方控制的平台，帳面數字可由平台顯示，無法單靠畫面驗證是真實資產。
先允許小額出金、加碼後再用各種理由卡住出金，符合常見的長期養套詐騙手法。

### 怎麼拆穿
> 只用「你自己掌控私鑰 / 自己開戶」的正規管道，絕不把錢匯到別人叫你匯的平台。
> 「要先另外繳錢才能領回你的錢」是高度危險訊號；遇到就先停手、不要再付，
> 並直接向金融機構與 165 查證，不要只聽對方客服說法。

## 通用守則

1. **主動找上門的「機會」，先預設是詐騙。** 真正的好機會不需要拉你、催你、保證你。
2. **看完整紀錄，不看精選截圖。** 倖存者偏差是所有投資詐騙的共同燃料。
3. **用期望值，不用勝率。** 高勝率會騙人；負期望值的策略，玩越久賠越多。
4. **錢只放自己掌控的帳戶。** 任何要你匯到「他指定平台」的，高度可疑。
5. **「要先另外繳錢才能領回你的錢」是高度危險訊號。** 不要再付，先向金融機構、
   165 或警方獨立查證。
6. **慢慢來，別賭。** 真正的優勢經得起統計檢定與時間考驗。

## 遇到詐騙怎麼辦？

**直接答案：停止匯款 → 保留證據 → 撥 165 → 報案。** 越快行動，
銀行端攔阻款項的機會越大。

- 立刻停止匯款、停止「升級」、停止下載對方指定的 App —— 包括任何
  「繳了就能領回」的解凍費、稅金、保證金（那正是詐騙的延續）。
- 保留所有對話、帳號、匯款紀錄（截圖 + 原始檔）。
- 撥打 **165 反詐騙諮詢專線**，或上 [165 全民防騙網](https://165.npa.gov.tw)
  查證與通報。
- 盡快向警察機關報案（[刑事警察局](https://cib.npa.gov.tw)），
  並聯繫銀行嘗試圈存款項。
